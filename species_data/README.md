# Species Data

This directory will hold versioned, data-driven species catalog definitions.

Requirements:
- Support broad taxonomic coverage and user-defined species.
- Keep species identifiers stable.
- Separate common names, scientific names, taxonomy, and localized labels where appropriate.
- Define optional and required attributes explicitly.
- Record provenance and validation status for husbandry guidance.
- Do not treat unsourced care ranges as authoritative.

The package format and schema are pending design.
