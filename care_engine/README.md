# Care Engine

This directory will contain universal care concepts and data-driven species-specific care definitions.

Planned responsibilities:
- Care templates and schedules.
- Recurrence and due-date rules.
- Species/life-stage/habitat-dependent attributes.
- Measurement definitions, units, and optional reference ranges.
- Source and validation metadata for guidance.

The engine must not present unsupported diagnoses or medication dosages. Unknown data must remain unknown, not zero.
