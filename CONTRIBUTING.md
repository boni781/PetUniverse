# Contributing to PetUniverse

PetUniverse is currently in product planning and repository foundation work.

## Before contributing

- Read the README and product/architecture documentation.
- Preserve the Personal and Professional workspace model.
- Keep the product multi-species and extensible.
- Do not assume species-specific fields apply to every animal.
- Keep unknown values distinct from zero.
- Record units and sources for care parameters and reference ranges.
- Treat offline behavior and synchronization as core requirements.

## Changes

- Keep changes focused and explain their purpose.
- Add or update tests when behavior changes.
- Never commit credentials, signing keys, private databases, personal attachments, or local environment files.
- Update documentation when product or architecture decisions change.
- Do not describe planned functionality as implemented.

## Commit messages

Use clear conventional-style messages, for example:

- `docs: refine habitat requirements`
- `feat: add animal profile model`
- `fix: prevent duplicate care log sync`
- `test: cover recurring care schedules`

## Pull requests

Describe the problem, intended behavior, design decisions, test evidence, and any migration or compatibility impact.
